# Trading Helper — Graphite Glass

Публичный статический макет интерфейса бэктестера Trading Helper. Без сборки и зависимостей: HTML, CSS, JavaScript и локальная копия lightweight-charts.

## Демо

После включения GitHub Pages:

- `https://zakharovellia.github.io/trading-helper-mockup/#backtest`
- прямая ссылка: `https://zakharovellia.github.io/trading-helper-mockup/mockups/graphite-glass/index.html#backtest`

Режимы: «День», «Бэктест», «Live». Переключение — в верхней панели; якорь `#backtest` открывает режим бэктеста.

## Локальный запуск

```bash
python3 -m http.server 8000
# http://127.0.0.1:8000/mockups/graphite-glass/index.html#backtest
```

Либо просто откройте `mockups/graphite-glass/index.html` в браузере.

## Важно

- Все данные, счета, сделки и метрики — демонстрационные.
- Ключи, токены и адреса кошельков заменены на заглушки; реальных учётных данных в репозитории нет.
- Это макет интерфейса, а не работающая торговая система и не инвестиционная рекомендация.
